01 · Once, about 10 minutes

Set it up

No terminal needed. Claude does the setup, and your only job is pasting two keys.

  1. Install Claude Code in VS Code. Open VS Code, click the Extensions icon in the left sidebar, search Claude Code, click Install, then sign in with your Claude account.
  2. Make an empty folder and open it. In VS Code go to File → Open Folder, create a new folder called Lead Scraper (in Documents is fine) and open it. Then click the Claude icon to open a chat.
  3. Paste this prompt into the chat and press Enter:
    Set up the Blue Wave AI lead scraper in this folder. Clone https://github.com/jun-qwickstep/bluewave-lead-scraper directly into the current folder, create my .env file from .env.example, and open .env so I can paste my keys. If git or Python 3 is missing, or GitHub asks me to sign in, walk me through it step by step. When you're done, tell me exactly where to paste each key.
  4. Paste your two keys into the .env file Claude opened, right after the = signs, then save (Cmd+S).
    Line in .envWhere to copy it from
    APIFY_TOKEN=console.apify.com → switch to the BlueWaveAI account → Settings → API & Integrations
    MILLION_VERIFIER_API_KEY=app.millionverifier.com → API in the left menu
  5. Start a new Claude chat and check. Click + for a new chat, then say check my setup. Claude confirms the keys work and which Apify account they belong to. That's it, you're ready.

02 · Every time

Run a scrape

You make three decisions. Claude handles the rest.

  1. Ask for what you want.
    Scrape flooring stores in Texas
  2. Answer a few questions. Claude fills in sensible defaults, so you can say yes or change one thing.
    InputWhat it meansDefault
    SegmentFlooring retailers or epoxy / coating contractorsYou choose
    State(s)One batch per state. It covers the whole state, no cities neededYou choose
    Search termsWhat gets typed into Google Maps. The core 5 cover most shopsCore 5
    Places per termHow deep to go. Small state 150, mid 300, CA / TX / FL 600–1,000300
  3. Approve the cost. You see the most it can spend on Apify, the MillionVerifier credits and your balances. Nothing runs until you say yes, and the Apify run has a hard cap, so it can't go over that number.
  1. Scrape. Google Maps is searched across the whole state, and the emails listed on each business's website are collected.
  2. Clean. Closed businesses, no-website listings, wrong categories (carpet cleaners, remodelers, furniture stores), junk emails, and anyone already in an earlier list are removed.
  3. Verify. Every email is checked by MillionVerifier. Only emails that pass make the list. Risky and invalid ones are dropped, so nothing on it should bounce.
  4. Get your list. Claude tells you what came out and where the file is.
The same store never lands on two lists. Each run checks every earlier list in leads/clean/. Don't delete those files, because they're how the scraper remembers who has already been contacted.

03 · The output

Where everything is

You only ever need one folder: leads/clean/. Everything else runs in the background.

leads/clean/Your finished lists. One CSV per scrape, verified emails only. Import these into Instantly.Start here
leads/raw/Everything Google Maps returned, before cleaning. Only for reference.
leads/runs.csvA log of every scrape: date, state, search terms, cost and lead counts.
config/Search terms and settings. Ask Claude to change them for you.
.envYour two API keys. Stays on your computer, never uploaded.
docs/This guide and the diagram.
.claude/The skill itself. No need to touch it.

Each scrape is named date_STATE_segment. So leads/clean/2026-09-24_TX_flooring_clean-712.csv is the Texas flooring list from Sept 24, with 712 verified emails.

05 · Good to know

Before your first run

  • Most emails are shared inboxes like info@ or office@. That's normal at this size, and they're tagged generic.
  • No revenue or owner names. Google Maps doesn't have them. Sort by review count instead.
  • Chains are flagged, not removed. Filter known_chain if you don't want them.
  • Apify's free plan ($5/mo) is for tests. A full state needs a paid plan.
