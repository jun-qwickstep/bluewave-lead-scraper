Mailboxes & campaigns

How the sending setup runs

01 · Warmup

Every mailbox warms up for 21 days

Instantly runs warmup automatically once a mailbox is connected. 21 days minimum before it sends a single cold email, and domain age doesn't count. Leave warmup on after launch, it holds reputation up while campaigns run. At full speed each mailbox sends 15 cold emails a day, so 450 a day across 30 mailboxes.

02 · Tags

Four tags, one per mailbox

Campaigns pull their senders by tag, so you move a mailbox between campaigns by changing its tag, never by picking addresses by hand.

TagMeaningWhen it gets used
warmingNew mailbox, still in its 21 daysSwap for insurance when warmup finishes
insuranceWarmed and ready, no campaign yetThe standby pool you pull replacements from
camp-<name>Sending for one campaign, e.g. camp-flooringNew campaign: create the tag, put it on the mailboxes you want sending, set Accounts to use to that one tag
recoveryHealth below 98%, resting on warmup onlyRemove its camp- tag, add this, pull a replacement from insurance. Back at 98%+, return it to the campaign. Still low after two weeks, retire it
Two rules that break things
One tag per mailbox (remove the old one when you add the new one) and one tag per campaign, because Instantly treats two selected tags as "or" and quietly pulls in mailboxes you didn't intend.

Set these every time

SequenceSendPurpose
Step 1Day 1The offer, short

Why: tracking pixels and rewritten links are spam signals, and opens don't book appointments. Three steps because the market is only ~12,000 businesses, so extra touches burn the list. Plain text only.

Before a campaign goes live
Mailboxes 21+ days warmed and at 98%+ · list verified and block list loaded · one camp- tag selected · tracking off, stop-on-reply on, limit 15 · spam test passed from those same mailboxes.
